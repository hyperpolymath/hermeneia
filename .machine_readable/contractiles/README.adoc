= Hermeneia Contractiles
:toc:
:sectnums:

This directory contains *Hermeneia's project-specific normative contracts*.
It is not the generic seed for other repositories. The reusable directory-shape
example is separate, under `machine-readable-design/canonical-directory-structure/`.

The six verbs define Hermeneia's north-star, hard requirements, trust boundary,
advisory accessibility and drift tolerances, cleanup/retirement policy, and
fail-closed stop conditions. The current text is a *provisional owner-review
draft*: the repository policy requires human supervision for invariant and
security-boundary changes. File presence and hash verification are not owner
ratification.

== Trident shape and local enforcement

Each verb has three paired files:

* `<Verb>file.a2ml` — the declaration and project-specific clauses;
* `<verb>.ncl` — the runner's expected schema and behavior;
* `<verb>.k9.ncl` — the declared trust tier, authority, and execution policy.

All six runner and K9 files import the project-local `../_base.ncl`; they do
not inherit the unrelated full-system-access profile under
`.machine_readable/self-validating/`. The K9 `tier` and `authority` fields
remain separate: `Hunt`/`Yard` describes capability, while reporting,
blocking, or advisory describes gate authority.

`<verb>.manifest.a2ml` sits beside them and pins the three content hashes,
byte sizes, and reciprocal paths. Run:

[source,sh]
----
bash scripts/verify-contractiles.sh
----

To refresh hashes *after reviewing an intentional edit*:

[source,sh]
----
bash scripts/verify-contractiles.sh --update-hashes
bash scripts/verify-contractiles.sh
----

The structural verifier is wired into the OpenSSF compliance workflow. It checks
trident presence, manifest hashes/sizes, registry entries, and literal pairing.
A separate CI step runs `extract-clauses.sh` and asserts it finds clauses across
all six declarations; that catches a silent-empty Coaptation inventory, but
still does not build the final receipt. The structural verifier does **not**
execute `probe` commands, parse Nickel, validate K9 semantics, prove that an
external CLI is installed, or imply maintainer approval.

[IMPORTANT]
====
This checkout does not include the `contractile` executable or a generated
`build/contractile.just`. Therefore commands such as `must check` and
`trust verify` are not currently available as project commands. The separate
Coaptation report runner (`just coapt` → `coapt.sh`) is present, but it does
not execute contractile probes. The `*.ncl` and `*.k9.ncl` files declare the
intended runner contracts; they are not evidence that those runners have
executed. The Rust, slice, placeholder, instantiation, and structural gates in
GitHub Actions are the currently wired checks.
====

The local K9 validator now mirrors the canonical
`hyperpolymath/k9-ecosystem/validate-action` implementation, including the
`.k9`/`.k9.ncl` dialect distinction and the schema-factored module handling
from standards#434. The four Hunt-tier tridents explicitly declare
`signature_required = true`; strict repository validation and the canonical
validator regression suite pass. This remains lexical validation: it does not
parse Nickel, verify cryptographic signatures, or replace the normative Nickel
contract still tracked by standards#1058. The K9 gate was not weakened.

== Hermeneia's six verbs

[cols="1,2,4",options="header"]
|===
| Verb | Authority | Hermeneia-specific role

| `intend`
| Reporting; never gates
| States Hermeneia's actual purpose and current evidence boundary: one
  implemented `invoke` slice, a local JSONL store, and an external
  `tropecheck` oracle. Records the remaining product actions and wishes.

| `must`
| Intended release-blocking gate
| Protects the five-crate workspace, honest implementation status, complete and
  hash-pinned tridents, reproducible instantiation, Rust unit tests, and the
  oracle-backed end-to-end slice. Each currently wired gate is named explicitly.

| `trust`
| Intended blocking security/integrity gate
| Treats query text, JSONL records, IR, and checker output as untrusted; keeps
  the grade algebra delegated to `tropecheck`; refuses to treat missing or
  malformed evidence as a pass. The default posture is a conservative proposal
  pending owner ratification. No external safe-hacking target is authorized.

| `adjust`
| Advisory; never blocks by itself
| Tracks plain-text CLI accessibility, actionable diagnostics, and truthful
  feature-status reporting. It makes no WCAG or GUI-conformance claim and
  authorizes no automatic fixes in this draft.

| `dust`
| Advisory; dry-run by default
| Identifies ignored build outputs and generated Coaptation intermediates while
  preserving tracked `build/` configuration, source history, tests, evidence,
  and rollback paths. No source or operation is approved for removal.

| `bust`
| Intended fail-closed gate
| Requires an explicit stop for unsupported operations, malformed/deceptive
  store data, missing checker, and unsupported loss/warrant output. Its probes
  are synthetic local tests, not destructive fault injection. No runtime expiry
  credential is asserted to exist.
|===

== Review decisions required before closure

The maintainer should confirm or amend these choices before this issue is closed:

. Whether `restricted` is the right proposed approval posture for changes to
  normative/security contracts, IR, proofs, releases, and destructive/external
  actions.
. Whether the trust boundary is complete: local CLI, local JSONL for now,
  `tropecheck` as the external oracle, and no network-facing service
  authorized. Decide whether `.machine_readable/integrations/verisimdb.a2ml`
  is an inactive optional feed or should be enabled under separate, explicit
  data-handling approval.
. Whether the Adjust tolerances are appropriate for a text-only CLI and
  AsciiDoc documentation, and which accessibility standard should apply if a
  graphical interface is later added.
. Whether the four Bust stop conditions are release-blocking, and whether any
  expiry-bearing authority or additional must-not-run condition exists.
. Whether Dust's two generated-artifact candidates and its no-unreviewed-removal
  rule are sufficient; no tracked source deletion is proposed here.
. Whether the Intend wishes and the status `contractile-specialization =
  in_progress` accurately reflect the project owner's priorities.

== Coaptation and remaining toolchain work

Nickel and compares it to `.machine_readable/coaptation/receipts/latest.a2ml`.
The receipt was already stale before this draft and must be regenerated after
the owner-approved declarations land. Do not hand-edit it. The current sandbox
has no Nickel executable, so that generated receipt cannot be refreshed here.
