# Canonical root allowlist for RSR-templated repositories.
#
# Lists every entry permitted at the repository root.
# Anything tracked at root that is not in this list is drift and
# must be moved into the appropriate subdirectory (or added here
# with a justification comment).
#
# Used by: scripts/check-root-shape.sh  (enforced by .github/workflows/estate-rules.yml)
# Authority: TEMPLATE-STANDARDS-AUDIT.adoc, "Proposed Final Directory Map"
#
# Format: one entry per line; '#' starts a comment; trailing '/' marks a directory.
# Blank lines and comment-only lines are ignored.
#
# This is a PERMISSION list, not a REQUIREMENT list: an entry here that is
# absent from the root does not fail the gate. Entries that are permitted but
# not currently present are marked PERMITTED-ABSENT below, and each says why it
# is still listed. Upstream hermeneia marks the same class with a `?`
# prefix; scripts/check-root-shape.sh here does not strip `?`, so the marker is
# a comment instead — a `?`-prefixed line would become an entry that can never
# match and would silently stop permitting the file it was meant to allow.
#
# Reconciled against the actual root at issue #8 (the placeholder/instantiation
# work): the list had drifted in BOTH directions — six entries present at the
# root were not permitted, and eleven permitted entries were not present.
