## Overview

This repository follows the **Hyperpolymath RSR Standard** for ABI and FFI design:

- **ABI (Application Binary Interface)** defined in **Idris2** with formal proofs
- **FFI (Foreign Function Interface)** implemented in **Zig** for C compatibility
- **Generated C headers** bridge Idris2 ABI to Zig FFI
- **Any language** can call through standard C ABI

## Why Idris2 for ABI?

### 1. **Formal Verification**

Idris2's dependent types allow proving properties about the ABI at compile-time:

```idris
-- Prove struct size is correct
public export
exampleStructSize : HasSize ExampleStruct 16

-- Prove field alignment is correct
public export
fieldAligned : Divides 8 (offsetOf ExampleStruct.field)

-- Prove ABI is platform-compatible
public export
abiCompatible : Compatible (ABI 1) (ABI 2)
```

### 2. **Type Safety**

Encode invariants that C/Zig cannot express:

```idris
-- Non-null pointer guaranteed at type level
data Handle : Type where
  MkHandle : (ptr : Bits64) -> {auto 0 nonNull : So (ptr /= 0)} -> Handle

-- Array with length proof
data Buffer : (n : Nat) -> Type where
  MkBuffer : Vect n Byte -> Buffer n
```

### 3. **Platform Abstraction**

Platform-specific types with compile-time selection:

```idris
CInt : Platform -> Type
CInt Linux = Bits32
CInt Windows = Bits32

CSize : Platform -> Type
CSize Linux = Bits64
CSize Windows = Bits64
```

### 4. **Safe Evolution**

Prove that new ABI versions are backward-compatible:

```idris
-- Compiler enforces compatibility
abiUpgrade : ABI 1 -> ABI 2
abiUpgrade old = MkABI2 {
  -- Must preserve all v1 fields
  v1_compat = old,
  -- Can add new fields
  new_features = defaults
}
```

## Why Zig for FFI?

### 1. **C ABI Compatibility**

Zig exports C-compatible functions naturally:

```zig
export fn library_function(param: i32) i32 {
    return param * 2;
}
```

### 2. **Memory Safety**

Compile-time safety without runtime overhead:

```zig
// Null check enforced at compile time
const handle = init() orelse return error.InitFailed;
defer free(handle);
```

### 3. **Cross-Compilation**

Built-in cross-compilation to any platform:

```bash
zig build -Dtarget=x86_64-linux
zig build -Dtarget=aarch64-macos
zig build -Dtarget=x86_64-windows
```

### 4. **Zero Dependencies**

No runtime, no libc required (unless explicitly needed):

```zig
// Minimal binary size
pub const lib = @import("std");
// Only includes what you use
```

## Usage

### From C

```c
#include "hermeneia.h"

int main() {
    void* handle = hermeneia_init();
    if (!handle) return 1;

    int result = hermeneia_process(handle, 42);
    if (result != 0) {
        const char* err = hermeneia_last_error();
        fprintf(stderr, "Error: %s\n", err);
    }

    hermeneia_free(handle);
    return 0;
}
```

Compile with:
```bash
gcc -o example example.c -lhermeneia -L./zig-out/lib
```

### From Idris2

```idris
import HERMENEIA.ABI.Foreign

main : IO ()
main = do
  Just handle <- init
    | Nothing => putStrLn "Failed to initialize"

  Right result <- process handle 42
    | Left err => putStrLn $ "Error: " ++ errorDescription err

  free handle
  putStrLn "Success"
```

### From Rust

```rust
#[link(name = "hermeneia")]
extern "C" {
    fn hermeneia_init() -> *mut std::ffi::c_void;
    fn hermeneia_free(handle: *mut std::ffi::c_void);
    fn hermeneia_process(handle: *mut std::ffi::c_void, input: u32) -> i32;
}

fn main() {
    unsafe {
        let handle = hermeneia_init();
        assert!(!handle.is_null());

        let result = hermeneia_process(handle, 42);
        assert_eq!(result, 0);

        hermeneia_free(handle);
    }
}
```

### From Julia

```julia
const libhermeneia = "libhermeneia"

function init()
    handle = ccall((:hermeneia_init, libhermeneia), Ptr{Cvoid}, ())
    handle == C_NULL && error("Failed to initialize")
    handle
end

function process(handle, input)
    result = ccall((:hermeneia_process, libhermeneia), Cint, (Ptr{Cvoid}, UInt32), handle, input)
    result
end

function cleanup(handle)
    ccall((:hermeneia_free, libhermeneia), Cvoid, (Ptr{Cvoid},), handle)
end

# Usage
handle = init()
try
    result = process(handle, 42)
    println("Result: $result")
finally
    cleanup(handle)
end
```

### ABI Verification (Idris2)

The ABI is verified by TYPECHECKING, not by a runtime script:

```bash
idris2 --typecheck abi.ipkg
```

`abi.ipkg` sets `sourcedir = src/interface` so the `module Abi.*` namespace
resolves; that is why the package is typechecked rather than each file passed to
`idris2 --check` individually. A bare per-file check reports "module name does
not match file name" and masks exactly the namespace/path breakage this is meant
to catch — `scripts/validate-template.sh` Phase 7 makes the same point.

Layout and alignment are discharged in `src/interface/Abi/Layout.idr` at compile
time, so there is no `verifyLayout` / `verifyAlignment` to call at runtime.
(This section previously showed an illustrative `%runElab verifyABI` script with
two corrupted identifiers in it; no such symbol exists in `src/interface/Abi/`.)

## Contributing

When modifying the ABI/FFI:

1. **Update ABI first** (`src/interface/Abi/*.idr`)
   - Modify type definitions
   - Update proofs
   - Ensure backward compatibility

2. **Generate C header**
   ```bash
   idris2 --cg c-header src/interface/Abi/Types.idr -o src/interface/generated/abi/hermeneia.h
   ```

3. **Update FFI implementation** (`src/interface/ffi/src/main.zig`)
   - Implement new functions
   - Match ABI types exactly

4. **Add tests**
   - Unit tests in Zig
   - Integration tests
   - ABI verification tests

5. **Update documentation**
   - Function signatures
   - Usage examples
   - Migration guide (if breaking changes)
