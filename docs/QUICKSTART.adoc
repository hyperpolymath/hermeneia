= Quickstart
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+
* just (command runner)
* Your language toolchain (see Justfile for details)

== Clone And Set Up

[source,bash]
----
git clone https://github.com/hyperpolymath/hermeneia.git
cd hermeneia
mise install                      # or: guix shell -D -f build/guix.scm
just                              # list recipes
----

This section used to be "== From Template (New Project)": instructions for
cloning this repository as a scaffold, wiping its git history and running
`just init` to render it into something else. That is what
https://github.com/hyperpolymath/rsr-template-repo[rsr-template-repo] is for.
hermeneia is an instantiation of it, already rendered — see
`.machine_readable/configs/instantiation.a2ml` for the values and
`scripts/instantiate.sh` for the pass. `just init` here is a repair-and-verify
command (idempotent; a rendered tree is a no-op), not a bootstrap.
