=== [Unreleased]

==== Added

* *Caller for the estate `CI/gate` commit status (2026-11-23).* The Branch-Floor
ruleset requires `CI/gate` but nothing in this repository produced it, so every
pull request was blocked. `+.github/workflows/ci-gate.yml+` is the suite's thin
caller, pinned to `+d28d73e+` of proven-cicd-and-workflows, which carries this
repository's required-check profile.

==== Fixed

* *Three more places said Vocarium does not exist (2026-11-17).* What does not
exist is the adapter to it (Vocarium's M2). `+ARCHITECTURE.adoc+` and
`+docs/SPEC.adoc+` (two places) now say the adapter is missing, and the header
of `+src/hermeneia-store/src/lib.rs+` adds that Vocarium's store engine is
built and gated in its own repository. The same sentence in
`+.machine_readable/+` is the owner's (#88).
* *Two documents credited the grade algebra's proof to Idris2 (2026-11-17).*
`+docs/SPEC.adoc+` and `+ARCHITECTURE.adoc+` now say what
`+docs/status/STATE-OF-PLAY.adoc+` says: the graded proof record is Agda, and
the Idris2 code is an engineering restatement outside the grade ladder.
* *The conformance step did not compare verdicts (2026-11-17).* It failed only
when the checker exited 2 or more, so a wrong verdict passed. It now reads each
fixture's expected verdict from `+cases.json+` and fails on a mismatch, on a
fixture with no expectation, and on an empty corpus.
* *The slice workflow tracked trope-checker's default branch (2026-11-17).* It
now pins the commit haec and vocarium pin, `+0dceab6+`. Between the siblings'
previous pin and that commit, trope-checker's `+src/+`, `+schemas/+`, `+spec/+`
and conformance fixtures are unchanged.
* *The scan workflow pin installed an Erlang version that crashes the scanner
on some trees (2026-11-17).* It moves to the revision trope-checker uses, which
installs OTP 27.3.4.19 (hypatia#1061).

* *`+docs/status/PROOF-STATUS.adoc+` published a percentage, which PROOF-POLICY
forbids (2026-11-09).* The summary read `+*Overall*: 0% proven+`. §8.4 rule 7 is
explicit — "Never publish 'X% proved', an average grade, or a single confidence
score" — and asks for a count per category with the denominator instead. The
figure was accurate; the form was the forbidden one. It now reads as a census,
with a note recording why. The same line ships in `+rsr-template-repo+`'s
`+PROOF-STATUS.adoc+`, so every repository minted from it carries the same
breach; fixing it there is the solution at source.

==== Added

* *A note saying what `+verification/proofs/+` actually contains (2026-11-09).*
`+docs/status/PROOF-STATUS.adoc+` now records that the directory is the unmodified
mint set, that none of it states a property of HERMENEIA, and that the 0%-proven summary
is therefore the accurate count rather than a backlog against those files. Also
records that nothing there supports a Proof Witness Grade under PROOF-POLICY §8.1,
and that removing the templates (as trope-checker did under ADR 0005 D5) is an
owner decision.

==== Added

- `coaptation`: `just check-coapt-identity` (`.machine_readable/coaptation/check-identity.sh`)
  — a toolchain-free identity gate enforcing issue #11's acceptance criterion:
  no template identity in the coaptation pack, and the committed receipt's `repo`
  must equal the `canonical-name` `CLADE.a2ml` declares. Runs in pre-commit and CI.
- CI: a `coaptation` job in `quality.yml` running both coaptation gates. Neither
  ran anywhere before, which is how the defects below went unnoticed.

==== Changed

- `coaptation`: the receipt's `repo` is DERIVED from `CLADE.a2ml`
  `[identity] canonical-name` rather than being a literal in the comparator, so
  it cannot silently revert to the scaffold's identity (issues #8, #11). If
  CLADE stops declaring a canonical-name the receipt says `repo = ""` — a
  visible hole rather than a plausible fiction.

==== Fixed

- `coaptation`: `extract-clauses.sh` matched clause headers with the interval
  expression `/^#{3,4} /`, which mawk — the default `awk` on Debian/Ubuntu, and
  therefore on every GitHub Actions `ubuntu-*` runner — does not support. awk
  does not error on an unsupported regex, it simply never matches, so `just
  coapt` exited 0 while emitting a well-formed receipt reading
  `clauses-total = 0`. Headers are now spelled out as portable ERE, and
  `verify.sh` refuses to accept a zero-clause reading at all.
- `coaptation`: the committed receipt was stale. Instantiation hand-substituted
  its identity line instead of regenerating it, so its provenance hashes named
  pre-instantiation contractiles and no committed state could reproduce it.
  Regenerated; the honest band is now `green`, not the stale `amber`.
- `self-validating/README.adoc`: the documented nickel download URL named a
  release asset (`nickel-linux-x86_64`) that no longer exists; `releases/latest`
  returned 200 with a "Not Found" body, installing a 9-byte shell script that
  failed later for an apparently unrelated reason. Now pinned to a version.
